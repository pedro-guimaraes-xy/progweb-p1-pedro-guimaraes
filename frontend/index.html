🏋️ Academia
Manager

Cadastre alunos, monte planos e controle as matrículas da sua academia em um painel simples, rápido e organizado.

Como funciona
JavaScript Bootstrap 5.3 Node + Express API REST

Como funciona

1

Cadastre os alunos

Nome e e-mail. Os dados são validados no front e de novo no backend.

2

Crie os planos

Mensal, trimestral, anual... com valor e duração em meses.

3

Matricule

Escolha aluno e plano. Um aluno não pode ter duas matrículas ativas.
